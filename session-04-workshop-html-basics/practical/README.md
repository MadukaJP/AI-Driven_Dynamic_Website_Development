# Practical: Portfolio Landing Page

Build `portfolio.html` using only what you've learned in Sessions 1–3.

## Required structure

```
<h1>Your Name</h1>
  <p> intro paragraph, with at least one <strong> and one <em> </p>
  <img ... alt="...">

<h2>Skills</h2>
  <ul> 4-6 skills </ul>

<h2>Timeline</h2>
  <ol> 3-5 milestones, e.g. "2022 - Started learning to code" </ol>

<h2>A Quote I Like</h2>
  <blockquote cite="..."> ... </blockquote>
```

Add a `data-section` attribute to each `<h2>`'s parent (e.g.
`data-section="skills"`) — this is prep for later sessions where we'll
select these with JavaScript.
