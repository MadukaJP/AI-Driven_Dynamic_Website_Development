# Session 4 Exercises: Self-Audit

Review your own `portfolio.html` from the practical and answer in
`audit.md`:

1. Does your page have exactly one `<h1>`?
2. Are all headings in order with no skipped levels?
3. Does every `<img>` have a meaningful, non-empty `alt` (or `alt=""` if
   purely decorative)?
4. Did you use `<strong>`/`<em>` for actual emphasis, not just visual
   styling?
5. Open DevTools → Elements. Is your HTML properly nested (no tags left
   open, no orphaned closing tags)?

Fix anything you find, then commit again.
