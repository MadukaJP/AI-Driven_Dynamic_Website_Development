# Session 4: Workshop — Combining Sessions 1–3

## What this session is

No new concepts today. This is a workshop: you combine everything from
Sessions 1–3 (web foundations, HTML basics, text formatting) into one
complete, real page.

## The build: a personal "Portfolio Landing" page

You'll build a single HTML page (no CSS yet — that starts Session 6) that
uses:

- A valid HTML5 boilerplate with `doctype`, `charset`, `viewport`, `title`
- Proper heading hierarchy (`h1` → `h2` → `h3`, no skipped levels)
- At least one image with a meaningful `alt`
- `<strong>` / `<em>` used correctly
- An unordered list (skills) and an ordered list (a short timeline)
- A `<blockquote>` with a `cite`
- A `data-*` attribute on at least one element (we'll use it with
  JavaScript later in the course)

See [`practical/README.md`](./practical/README.md) for the full spec.

## Where AI fits in

Before you start, ask your AI assistant to review your **plan**, not
write the code:

```
I'm about to build an HTML page with: an intro section, a skills list,
a short timeline, and a quote. What order and heading structure would
you suggest for good accessibility?
```

Use its answer as a sanity check, then build it yourself.
