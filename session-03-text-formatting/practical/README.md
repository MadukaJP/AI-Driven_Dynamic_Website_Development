# Practical: Formatting a Blog Post

Build `blog-post.html`.

## Steps

1. Add an `<h1>` title and an `<h2>` subheading.
2. Write 2 paragraphs of body text, using `<strong>` and `<em>` at least
   once each where the meaning genuinely calls for it (not just for style).
3. Add a `<blockquote>` quoting someone (real or made up), including a
   `cite` attribute.
4. Add an unordered list of "3 takeaways" from your post.
5. Add a code snippet using `<pre>` and `<code>` together:
   ```html
   <pre><code>your code here</code></pre>
   ```
