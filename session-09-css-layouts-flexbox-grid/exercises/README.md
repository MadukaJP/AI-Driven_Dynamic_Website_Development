# Session 9 Exercises

## Exercise 1: Flexbox or Grid?

For each scenario, say whether Flexbox or Grid is the better fit, and why:
1. A row of 4 navigation links
2. A photo gallery with rows and columns
3. A page with a fixed sidebar and a main content area
4. A group of buttons that should wrap on small screens

## Exercise 2: Build a responsive card grid

Create `cards.html` + `cards.css` with 6 `.card` divs in a
`display: grid` container using `auto-fit` and `minmax()`, so it
reflows from 1 to 3 columns depending on screen width — no media
queries.

## Exercise 3: Fix the layout

`broken-layout.css` tries to center items in a flex row but gets it
wrong. Fix it.
