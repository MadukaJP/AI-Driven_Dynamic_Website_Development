# Practical: Style Your Portfolio Page

Take `portfolio.html` from Session 4 and add a `styles.css` file.

## Steps

1. Link the stylesheet: `<link rel="stylesheet" href="styles.css">`
2. Define CSS custom properties in `:root` for your primary color, a
   secondary color, and 2-3 spacing values.
3. Style your headings, paragraphs, and lists using element selectors.
4. Add a `.card` class to your "Skills" section and style it with a
   border and padding (using your spacing variables).
5. Style your links, including `:hover` and `:focus` states — do not
   remove the focus outline.
6. Bonus: use `:has()` to style your `.card` differently if it contains
   an image.
