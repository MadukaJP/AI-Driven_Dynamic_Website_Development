# Session 12 Exercises: Self-Assessment

Go through your own capstone with fresh eyes and write `self-review.md`
answering:

1. If you removed all CSS, would the page still make logical sense
   just from its HTML structure and heading order?
2. Could someone using only a keyboard (no mouse) fill out and submit
   your contact form? Try it — tab through the form yourself.
3. Is there anywhere you used a `<div>` where a semantic tag would have
   been more accurate?

Fix anything you find.
