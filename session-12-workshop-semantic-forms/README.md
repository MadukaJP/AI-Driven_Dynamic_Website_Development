# Session 12: Workshop — Semantic HTML & Forms

## What this session is

A workshop combining Sessions 9–11: layouts, semantic structure, and
forms — all applied to the capstone.

## What you'll build

👉 **[Click here to see what you'll build today](https://local-bites.netlify.app/)**

## The build

1. Review your capstone `index.html` and `contact.html` against the
   checklist in `practical/README.md`.
2. Add a simple newsletter signup form to your homepage footer (new —
   not covered explicitly before, so this is your chance to apply what
   you know independently):
   - Email input, required, with a label (can be visually hidden but
     present in the DOM for accessibility — see the practical for how)
   - A submit button
   - Uses Flexbox to lay the input and button out in a row

## Where AI fits in

```
Review my capstone's index.html and contact.html for: correct semantic
tags, proper label/input pairing, and any missing required attributes.
[paste both files]
```

Use this as a genuine second-opinion code review, the way you'd ask a
colleague — but make your own call on what to change.
