# Session 7 Exercises

## Exercise 1: clamp() practice

Write a `clamp()` value for a paragraph's font-size that should never go
below 14px, prefers 2vw, and never exceeds 18px.

## Exercise 2: Style a pull-quote

Given this HTML:
```html
<blockquote class="pull-quote">Design is not just what it looks like. Design is how it works.</blockquote>
```

Write CSS in `pull-quote.css` giving it: a large italic font, centered
text, and a top/bottom border.

## Exercise 3: Fix the span

`bad-span.html` uses inline `style` attributes instead of a class. Refactor
it to use a `.highlight` class in a separate stylesheet.
