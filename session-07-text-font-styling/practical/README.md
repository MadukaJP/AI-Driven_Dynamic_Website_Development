# Practical: Typography Pass on Your Portfolio

Continue styling `portfolio.html`.

## Steps

1. Add a Google Font of your choice (try 'Inter', 'Poppins', or 'Roboto').
2. Set your `<h1>` font-size using `clamp()` so it scales between mobile
   and desktop.
3. Add a `.highlight` span class and use it around one important word or
   phrase in your intro paragraph.
4. Style your `<blockquote>` with a left border and italic text.
5. Set comfortable `line-height` (1.5–1.7) on your body text.
6. Resize your browser window (or use DevTools responsive mode) and
   confirm your heading scales smoothly.
