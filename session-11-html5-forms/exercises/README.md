# Session 11 Exercises

## Exercise 1: Pick the right input type

For each field, name the best HTML5 `type`:
1. A birthdate
2. A website URL
3. A quantity between 1 and 20
4. A search box
5. A favorite color picker

## Exercise 3: Add native validation

`unvalidated-form.html` so it can't be submitted with missing or
invalid data.
