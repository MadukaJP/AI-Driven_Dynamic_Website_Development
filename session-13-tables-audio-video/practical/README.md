# Practical: Local Bites Menu Page

Create `../../capstone/menu.html`.

## Steps

1. Start from the boilerplate, link the shared stylesheet.
2. Build a `<table>` listing at least 6 dishes with columns: Dish,
   Description, Price, Calories.
3. Use `<thead>`/`<tbody>` and style the table (borders, padding,
   `width: 100%`).
4. Add one `<img>` per featured dish using `srcset` + `sizes` (you can
   use placeholder image URLs from https://picsum.photos for now, e.g.
   `https://picsum.photos/400/300`) and `loading="lazy"`.
5. Add a short `<video>` "kitchen tour" section with `controls`, a
   `poster`, and a `<track kind="captions">` (the caption file itself
   can be a stub — the point is the markup).
6. Link "Menu" in your nav to this page.
