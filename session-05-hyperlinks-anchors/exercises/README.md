# Session 5 Exercises

## Exercise 1: Absolute or relative?

Given a site structure:
```
/index.html
/about.html
/blog/post-1.html
```

Write the correct relative `href` to link:
1. From `index.html` to `about.html`
2. From `blog/post-1.html` back to `index.html`
3. From `index.html` to `blog/post-1.html`
