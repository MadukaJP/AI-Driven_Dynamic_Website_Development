# Practical: A One-Page Site with Navigation

Build `one-pager.html` with:

1. A `<nav>` at the top with links to 3 sections on the same page
   (using anchors, e.g. `#about`, `#projects`, `#contact`).
2. Three `<h2>` sections matching those anchors, each with 2-3 sentences
   of content.
3. At least one external link (e.g. to your GitHub profile or LinkedIn)
   using `target="_blank" rel="noopener noreferrer"`.
4. One `mailto:` link with a pre-filled subject.
5. A "Back to top" link at the bottom of the page linking to an `id="top"`
   you add to your first heading.
