# Capstone Project: "Local Bites" — A Small Business Website

Starting in **Session 9**, you'll build this project incrementally, one
feature per session, instead of a disconnected exercise. By Session 20
you'll deploy a real, working, AI-enhanced website.

## The brief

You're building the website for **Local Bites**, a fictional small
neighborhood café. It needs:

- A responsive homepage (Session 9: Flexbox/Grid layout)
- Semantic structure and a navigation bar (Session 10)
- A contact/reservation form (Session 11)
- A menu page with a table and food photos/video (Session 13)
- Interactive JavaScript features — a menu filter, form validation
  (Sessions 14–16)
- A "save your favorite dishes" feature using Web Storage and a Canvas-
  drawn loyalty card (Session 17)
- A "find your nearest location" feature using Geolocation, plus an
  AI-powered chatbot widget answering menu questions (Session 18)
- Mobile-first responsive polish and PWA basics (Session 19)
- Deployment to Netlify/Vercel with a CI check (Session 20)

## How to use this folder

Each relevant session's `practical/README.md` tells you exactly what to
add to this folder. Work directly in here — don't rebuild from scratch
each time. Commit after each session's addition.

## Structure (grows over time)

```
capstone/
├── index.html          Homepage
├── menu.html            Menu page (added Session 13)
├── contact.html          Contact/reservation form (added Session 11)
├── css/
│   └── styles.css
├── js/
│   └── main.js
└── assets/               Images, icons
```

## Feel free to make it your own

"Local Bites" is a starting brief, not a cage — rename it, change the
business type (bookstore, gym, tutoring service, whatever you like), as
long as you hit the same technical requirements each session asks for.
